# MemScape simulation publication

The user requested a browser simulation linked from the product page on
2026-10-28. This publishes the existing fictional, session-only MemScape web UI,
not an account-backed journal. The hero CTA links to `/demo/`; the notice says
fictional memories, edits reset on reload, no sync. Existing native screenshots,
TestFlight links and product analytics are preserved. The demo page carries the
same Plausible tag as the product page, so visits appear as `/demo/` in the
`mem.scapedeck.com` dashboard; the `/demo/*` policy allows that origin for
`script-src` and `connect-src` and nothing else.

The snapshot is generated by `scripts/export-demo.py` in the separate private
`memscape-web` repository from a committed Git archive and locked offline
wasm-pack build. `demo-manifest.json` records the exact source, toolchain and
hashes. The JavaScript glue, WASM, snippet module tree and notices are included.
Only eight canonical synthetic photos are served under the app's existing
root-relative photo URLs. No standalone journal JSON, Rust source or private
fixtures are copied. Generated JavaScript and its required source snippets are
runtime assets. These committed artifacts are deployment inputs; this repository does
not contain their application build source.

wrangler whoami
